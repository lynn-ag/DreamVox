DreamVox v0.2 Dreamscape - Windows x64 VST3 preview

1. Close FL Studio. Back up your existing DreamVox.vst3 bundle outside all plugin scan folders.
2. Extract this download. Copy the complete DreamVox.vst3 folder (including Contents) into:
   C:\Program Files\Common Files\VST3\
   Administrator permission may be needed.
3. Open FL Studio: Options > Manage plugins (or Options > File settings > Manage plugins).
   Enable Verify plugins and Rescan previously verified plugins, then Find installed plugins.
4. Add DreamVox to a Mixer effect slot. The interface should show V0.2 DREAMSCAPE.
5. Test on a copy of a project: turn knobs, check bypass, close/reopen the editor,
   then save and reload the project to check settings recall.

This preview retains v0.1's plugin identity and parameter IDs. It replaces the installed
v0.1 for testing; do not install both copies in scan folders. Keep the backup.
To roll back: close FL Studio, replace the v0.2 bundle with the saved v0.1 bundle,
then rescan. The main branch and existing v0.1 build remain unchanged.

BUILD.txt records the source commit, Actions run and binary SHA256.
pluginval.log records automated validation. An automated pass is not a guarantee
of FL Studio compatibility; the host smoke test above is still required.
