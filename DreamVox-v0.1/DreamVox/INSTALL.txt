DREAMVOX 5 NEON — WINDOWS x64 VST3

This is a separate plugin from the original DreamVox.
It has its own product name, VST3 plugin code and bundle ID.
Do NOT rename an old DreamVox.vst3 bundle to DreamVox 5.vst3.

BUILD AND DOWNLOAD
1. Open https://github.com/lynn-ag/DreamVox/actions
2. Select the latest successful "Build DreamVox 5 Neon VST3" run
   on branch "feature/neon-dreamvox-ui".
3. Download the "DreamVox-5-Neon-Windows-VST3" artifact.
4. Extract the ZIP. Copy the ENTIRE folder "DreamVox 5.vst3" into:
   C:\Program Files\Common Files\VST3\
   Keep its Contents folder and all files inside it together.
5. Leave your original DreamVox.vst3 installed and untouched.
6. Restart FL Studio, go to Options > Manage plugins, and scan
   without selecting "Rescan previously verified plugins".
7. Search for "DreamVox 5". Verify it loads as an Effect.

The GUI uses bundled moonlit artwork as a backdrop for fourteen
real knobs, presets and bypass. The PNG is a flattened reference;
its painted controls are NOT independent interactive widgets.
The controls above the backdrop are the functioning DSP controls.

IF THE BUILD FAILS
Open the failed GitHub Actions run, select "Windows x64 Release",
expand the red step, and read/copy the first error.

IF THE WRONG GUI APPEARS
Check that the GitHub Actions run is NEWER than the "Package DreamVox 5
bundle separately from original DreamVox" commit and that you installed
"DreamVox 5.vst3" from that exact successful run, not a renamed old bundle.
Close and reopen FL Studio after replacing the new bundle.

This is a development build, not a validated commercial release.
Test controls and audio carefully before using it in a production project.
