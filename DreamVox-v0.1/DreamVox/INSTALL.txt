DREAMVOX 0.1.1 - WINDOWS x64 VST3

INSTALL
1. Close your DAW and pluginval.
2. Extract this ZIP.
3. Move your old DreamVox.vst3 folder out of the VST3 scan folders as a backup.
4. Copy the entire new DreamVox.vst3 folder to:
   C:\Program Files\Common Files\VST3\
   Keep the Contents folder and everything inside it together.
   Approve Windows administrator permission if asked.
5. Restart your DAW, rescan plugins, and open DreamVox.
   The editor should show V0.1.1.

VALIDATION
The build workflow only creates this download after pluginval 1.0.4 passes
at strictness level 5 with GUI tests enabled and three repeats.
See validation/pluginval.txt for the actual results and BUILD.txt for source.
These tests do not guarantee compatibility with every DAW or audio device.

CHANGE
Create all editor controls before setting the editor size. Previously the
initial resize accessed empty arrays while the editor was being constructed.
Parameter IDs, plugin IDs, and saved-state format are unchanged.
