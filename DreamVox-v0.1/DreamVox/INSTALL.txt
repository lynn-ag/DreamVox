DREAMVOX 5 — FUNCTIONAL EFFECT SUITE (WINDOWS x64 VST3)

This is an experimental JUCE vocal-processing VST3 with a distinct plugin ID
from the original DreamVox. Your original DreamVox.vst3 remains separate.

INSTALL THE CORRECT BUILD
1. Open https://github.com/lynn-ag/DreamVox/actions
2. Find the LATEST successful "Build DreamVox 5 Neon VST3" run.
   Its branch must be "feature/dreamvox5-velvet-ui".
3. Under Artifacts, download "DreamVox-5-Neon-Windows-VST3".
4. Extract the ZIP. Copy the WHOLE folder "DreamVox 5.vst3" into
   C:\Program Files\Common Files\VST3\
   Keep its Contents subfolder and all files.
5. Replace the earlier DreamVox 5.vst3 installation if it exists.
   DO NOT DELETE OR REPLACE the different "DreamVox.vst3" bundle.
6. Restart FL Studio and run Options > Manage plugins > Find installed
   plugins with "Rescan previously verified plugins" OFF.
7. Open DreamVox 5 as an effect on a mixer insert. Play audio through it.

HOW TO USE
- Eight clickable neon jewel cards: CLEAN, COMP, EQ, DE-ESS, TONE,
  SPACE, ECHO and DOUBLER. Click a card to open its own DSP controls.
- "Choose an effect preset..." applies ONLY that module's parameters.
  Each of the 8 modules has 4 relevant presets (32 module presets).
- "Select a chain preset..." applies one of the 24 whole-vocal presets.
- Input/output stereo peak meters, output waveform, FFT spectrum and
  compressor/de-esser reduction readings use live processor signal data.
- The always-visible OUTPUT control changes overall output level;
  BYPASS disables processing while monitoring stays active.
- New Clean high-pass and gate-floor controls, adjustable compressor
  attack/release, de-esser detector frequency and doubler spread work
  through the audio processor.
- Your changes to parameters are saved with the FL Studio project.
- Moonlit imagery is cropped to the HEADER only. The effect cards,
  sliders, menus, meters and detail panel are real JUCE components.
  The background image is decorative and NOT an interactive control.

LIMITATIONS
- Effect presets are built-in choices, not a save-custom-preset system.
- The current compressor, de-esser and gate are prototype DSP and need
  listening/measurement tests for musical accuracy.
- Spectrum is an FFT snapshot, not a calibrated loudness analyzer.
- No claim of commercial-grade mastering, tuning, harmony-generation,
  independent module bypasses or microphone capture outside FL Studio.
- FL Studio sends audio to this VST3; a live microphone requires routing
  the microphone to the same mixer insert.

If the build fails, open its GitHub Actions run and read the FIRST error
from the Build VST3 or Prepare downloadable plug-in step.
